## 決定事項

| ID | 内容 | 決定 |
|---|---|---|
| D-01 | リポジトリ名 / パッケージ | `tamacat-monitor` / `org.tamacat.monitor` |
| D-02 | Zabbix 連携方式 | 参照・更新とも DB 直接。API はテストでの正解作成のみ |
| D-03 | UI 方式 | JSP シェル + Cloudscape React アイランド |
| D-04 | JSON ライブラリ | Jakarta JSON-P（Eclipse Parsson） |
| D-05 | タグライブラリ | JSTL（Jakarta Standard Tag Library）を使う |
| D-06 | テンプレートのリンク | P6 で範囲を限定して対応（T-601）：Zabbix エージェント / アクティブ / トラッパーのアイテムとそのトリガー・グラフだけのテンプレート。ディスカバリルール・Web シナリオ・入れ子・その他のタイプを含むものは Zabbix のフロントエンドで。テンプレート由来のアイテムは引き続き編集不可 |
| D-07 | アクションの通知先 | Zabbix 既存のユーザー / ユーザーグループを参照して選ぶだけ |
| D-08 | 監査ログ | 統合管理 DB の `audit_log` のみ（Zabbix の `auditlog` には書かない） |
| D-09 | アクションの権限 | 編集は `SERVER_ADMIN` 以上。一般ユーザーは許可範囲のアクションログを参照のみ |
| D-10 | tamacat-logging | 1.0.0（公開済み）を使う |
| D-11 | Tomcat バージョン | tamacat-httpd 1.7 の pom.xml に従い 11.0.29 |
| D-12 | tamacat-dao | 本リポジトリ（`tamacat-monitor-dao`）に取り込んで改良する。本体へ還元するかは後で決める |
| D-13 | コネクションプール | 独自実装。Tomcat に依存しない（アプリコード全体で Tomcat 固有クラスを使わない） |
| D-14 | 画面の文言 | サーバー側 ResourceBundle に一本化し、画面へは初期データで渡す。API のエラーはメッセージキーで返す |
| D-15 | Zabbix DB の JDBC URL | 許可リストで検証（認証情報・危険なドライバオプションは不可） |
| D-16 | サブグループ | スコープ単位のフラグ。Zabbix 上の現在の名前で `親/` に前方一致するグループを含める |
| D-17 | 参照の権限強制 | Reader は `AccessScope` を必須引数とし、SQL の `exists (... groupid in (...))` で強制する |
